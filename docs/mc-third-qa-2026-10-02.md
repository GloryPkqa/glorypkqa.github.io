# MC 工具工坊第三轮检测

日期：2026-10-02。基于第二轮已发布的 `fc3e7ec`，重新运行全部检查，并针对预览与输出的一致性、复制异步状态、键盘操作、披风异常恢复和长文字布局补测。

## 本轮发现并修复

| 问题 | 复现与修复 |
| --- | --- |
| 标题空格导致逐字配色错位 | 输入 ` A `，选择第二字 A 上色；旧指令先 trim，A 错用第一个空格的颜色。保留原文，三个标题区域的预览和指令使用相同字符索引。 |
| 预览丢失连续空格及换行 | 聊天输入两行或连续空格，指令保留、浏览器预览却折叠。预览改为保留空白并允许换行。 |
| 输入的 § 符号被删除 | 输入 `价格§10`，旧输出变为 `价格10`。保留全部原文；传统格式输出旁说明内嵌格式码仍可能由游戏或插件解释。 |
| 垂直目标误报已到达 | 起点 `(800,64,-1600)`、终点 `(800,80,-1600)`，旧提示“已经到达目标”。现为“正上方”；负高度差为“正下方”，三个坐标一致才显示到达。 |
| 药水小数的预览和输出不同 | 输入 1.5 秒，旧摘要 1 秒，指令 30 刻。药水行的秒数和等级统一为整数，现显示 1 秒并输出 20 刻。 |
| 修改指令后仍显示已复制 | 原提示仅绑定按钮，不绑定文本；延迟的权限请求、旧计时器也可能覆盖新状态。10 处复制交互共用状态逻辑，成功提示绑定实际复制文本，旧请求和旧计时器无法覆盖新结果，卸载清理计时器。 |
| 披风预览失败后不恢复 | 某张贴图加载失败后，failed 一直为 true，canvas 被移除，换贴图也无法重建。失败状态按贴图地址记录，保留可恢复的 canvas，失败时释放观察器和渲染器。 |
| 隐藏的返回按钮仍进入键盘顺序 | 顶部按钮透明时仍可以 Tab 选中。隐藏状态移出键盘顺序和辅助阅读树，显示后恢复；两个返回入口均遵守减少动画偏好。 |
| 手机长操作栏预览被裁切 | 输入 100 个连续 W，390 像素视口中预览宽约 914 像素，文字伸出卡片。限制到卡片宽度并自动换行；320、390、768、1440 像素复查通过。 |
