# MC 工具工坊第二轮深入检测

日期：2026-10-02。基于上一轮已发布的 `1b5bfde`，检查 15 个工具、9 个 Java 版本，以及个人主页。本文记录新增检查；上一轮全功能检测见 `mc-qa-2026-10-02.md`。

## 本轮修复

| 问题 | 修复与验证 |
| --- | --- |
| 选中新版附魔后切到旧版，仍能添加不可见的附魔 | 按当前目录判断待添加附魔；不支持时按钮禁用，事件处理也拦截。真实网页复现并复测；49 组版本切换用例。 |
| 数据包允许导入当前版本不存在的附魔或无效文本属性 | 导入时核对当前目录、附魔 ID、文字类型、颜色、样式和嵌套文本；目录未完成加载时拦截导入。覆盖普通物品与附魔书、4 个组件版本和错误输入。 |
| 一个图标加载失败后，换物品仍永久显示占位符 | 失败状态关联图片 URL；新 URL 能重新加载，旧图片迟到的错误不会隐藏新图片。 |
| 页面初始自动查询可能覆盖用户刚输入的新名字 | 修改输入或手动查询时取消尚未开始的默认查询；默认 Pkqa 自动查询仍保留。 |
| 玩家、版本、服务器接口异常内容可能使 React 渲染失败 | 验证实际使用的返回字段；异常版本数据显示可恢复错误，异常服务器数据走备用查询，异常玩家资料显示提示。用真实 React 服务端渲染复现旧错误并验证修复。 |
| 基岩版状态接口返回版本号，但页面显示“未知” | 增加 `version.name` 字段读取；保留 Java 的 `name_clean/name_raw`。接口文档用例和在线演示接口均通过。 |
| 版本目录请求可能一直处于加载中；不匹配数据可能使工具崩溃 | 增加 10 秒超时、请求取消、目录结构与版本检查、重新载入按钮；81 组版本请求切换以及超时和重试用例。 |
| 逐字上色拆开组合 emoji、国旗和重音字母 | 以完整可见字符分组；家庭 emoji、肤色 emoji、国旗、组合重音字母均覆盖。旧浏览器缺少分组接口时保留原有兼容回退。 |
| 缩短文字后，保留不可见的选中文字，点颜色无反应 | 选中状态与当前文字及编辑区域关联；编辑文字后以当前文字重新选择。真实网页复测从第五个字缩短为一个字。 |
| 旗帜复制失败产生未处理异常 | 捕获剪贴板拒绝并提示手动复制；下一次复制成功后清除错误提示。 |
| 填充上限提示在旧版本和 26.1 使用错误的游戏规则名 | 旧版本说明固定上限；1.19.4 起使用原规则名；1.21.11 起使用 `minecraft:max_block_modifications`。逐版本验证提示。 |

## 测试证据

- 新增 `pnpm check:deep`，纳入拉取请求与发布检查。共 **888 个新增用例**：72 个目录异常、81 组请求切换、49 组附魔切换、81 组药水切换、388 个导入用例、12 个组合字符用例、205 个其他状态及恢复用例。
- 改进组件测试的生命周期模拟：依赖变化会执行清理并重新运行效果；另用真实浏览器检查 React 与页面交互。模拟测试不等于游戏内执行。
- 已重新通过原有指令、扩展功能、药水、玩家、全目录和交互检查，以及 ESLint、TypeScript 和静态导出构建。
- 正式静态构建在本地预览服务上检查 9 个版本：目录链接均对应存在的区域；1.8.9 显示 9 个工具，1.12.2 显示 10 个，其余显示 15 个；颜色格式与传送目标按版本变化。
- 连续切换药水版本：新版独有效果在旧版本被排除，回到新版后恢复；导入物品属性在旧版本不会写入配方。
- 当前网页查询 Notch 成功，姓名与 UUID 正确更新。服务器默认地址仍为空。
- mcstatus 的官方基岩版演示地址 `demo.mcstatus.io:19132` 返回在线、玩家数和 `1.19.70`；网页正确显示版本。该地址仅用于测试，没有设为网站默认值，也没有验证游戏客户端连接。
- 主页真实浏览器检查：随机语句确实变化；收藏在重新加载后保留；测试收藏已清除。
- 320、390、768、1440 像素视口检查：页面没有横向溢出，表单、输出面板和目录卡片未超出视口。实际读取视口尺寸确认设置生效。
- 使用独立于 ZIP 生成器的 .NET 解压读取器检查 **43 个 ZIP、100 个文件**：7 个数据包版本 × 有序/无序 × 配方/战利品/两者，以及中文与 emoji 文件名、空文件。中央目录、文件名及解压后内容均一致。临时测试包保存在忽略目录 `coverage/deep-zip`。

## 官方核对依据

- [1.20.5 物品组件格式](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-20-5)：旧组件版本的名称是 JSON 文本字符串。
- [1.21.5 文本与 SNBT 格式](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-5)：新版文本直接嵌入结构，支持扩展字符串转义。
- [1.19.4 游戏规则](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-19-4)：新增方块修改数量规则。
- [1.21.11 游戏规则改名](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11)：规则迁入命名空间并改名。
- [mcstatus API 文档](https://mcstatus.io/docs)：Java 与基岩版版本字段不同；基岩版玩家数可以为 null。

## 验证范围

本轮覆盖代码、静态构建、浏览器交互、异常输入、网络故障模拟、外部演示接口和 ZIP 内容读取。**没有在 9 个真实 Minecraft 客户端/服务器中执行全部指令或加载数据包，也没有验证真实手机保存 ZIP 的完整流程**。浏览器视口测试不能代替实体手机测试。外部查询仍会受到提供方缓存、网络与可用性影响。

公开推广前仍建议在目标游戏版本中实际执行代表性指令并加载数据包；当前结果不能表述为“绝无 bug”。
