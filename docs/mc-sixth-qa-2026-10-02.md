# MC 工具工坊第六轮检测

日期：2026-10-02。基于已发布的 `b957338`。

## 发现并修复

| 问题 | 复现 | 修复 |
| --- | --- | --- |
| 完整物品 ID 搜索无结果 | 工作台输入 `minecraft:diamond_pickaxe`，原来找不到钻石镐 | 工作台、进阶配方搜索统一接受 `minecraft:` 前缀、大小写及两端空白 |
| 酿造材料 ID 无法搜索 | 输入 `blaze_powder`，原来没有力量药水结果 | 搜索包含材料原始 ID；熔炼、切石和锻造也包含材料与产物 ID |
| 药水数字框无法清空重填 | 删除时长后立即变成 1，再输入 1200 会影响编辑 | 单效果与多效果药水允许暂时留空；未填完时暂停生成、禁用复制并提示；完整输入继续保留取整和上下限处理 |
| 未确认的新草稿丢掉已导入属性 | 成功导入带名称的剑，再编辑新指令或导入失败，原配方原来变成普通剑 | 已确认属性与草稿独立保存；明确提示配方仍使用上次导入内容；成功重新导入或主动清除才替换属性 |
| 旗帜旧复制错误残留 | 剪贴板拒绝后修改旗帜，旧错误仍显示 | 错误绑定对应指令；修改图案隐藏旧错误；旧异步失败不能覆盖新的复制成功 |
| 旧版颜色预览与实际输出不同 | 1.8 / 1.12 使用 RGB、渐变或逐字色，命令实际使用经典 16 色，预览原来保留 RGB | 聊天与各标题预览映射到命令实际输出的经典色；切回新版保留用户原始配色 |
| 文件名空白导致属性导入后预览定位错误 | 配方文件名为 `  lucky_diamond  `，导入成功后预览原来回到 `pack.mcmeta` | 预览路径与生成文件一致，去掉文件名两端空白 |

第三轮测试原来要求清空药水时长后自动填 1，本轮更新为保留空白、禁用复制；原有小数、负数、上限检查继续保留。

## 真实页面验证

- 最终静态页面：工作台搜索 `minecraft:diamond_pickaxe` 返回钻石镐；酿造搜索 `minecraft:blaze_powder` 返回力量药水。
- 390 像素手机布局：单效果和多效果时长能清空并禁用复制，逐字输入 1200 后命令正确；药水对应 24,000 游戏刻。
- 带名称产物成功导入；编辑草稿及故意导入错误指令后，预览 JSON 中原名称仍保留，并显示未确认草稿提示。
- 旧版渐变预览的逐段颜色与命令中经典颜色一致。
- 9 个版本逐一加载成功；1.8.9 提供 9 个工具、1.12.2 提供 10 个，其他版本提供 15 个。
- 320 / 390 / 768 / 1440 像素宽度没有整页横向溢出。
- 本地浏览器验证未记录控制台错误。
