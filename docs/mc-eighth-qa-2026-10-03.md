# MC 工具工坊：旧版引擎与 JVM 深入复查

日期：北京时间 2026-10-03 凌晨。先完成并发布第 16 / 17 区，再针对单纯语法检查发现不了的真实引擎行为、运行时版本与页面加载继续检查。计划于 02:00 停止新增工作。

## 新发现及修复

1. **旧版药水高等级实际丢失。** 1.20.4 及更早版本将药水 amplifier 当有符号 byte 读取；128 / 254 / 255 实际被读成 0，不能仅因为命令语法解析成功就认定有效。网页药水上限统一为显示等级 128（amplifier 127）；1.20.5 起仍支持显示等级 256（amplifier 255）。普通 `/effect` 的等级限制单独保留。真实页面验证旧版输入 256 显示 128、输出 127，新版输出 255，旧版普通效果仍输出 255。
2. **NBT 空属性名未被旧版校验拦截。** 官方 1.16.5 与现代解析器均拒绝 `{"":1}`；现在所有版本的目标 NBT 都拒绝空 key，合法的空字符串值保持支持。增加复合标签、选择器、物品和标题工具的正负控；真实页面无效目标暂停输出 / 复制。
3. **首页提前加载了披风 3D 依赖。** 披风预览在进入玩家档案附近时才加载，保留失败占位和资源清理。真实页面顶部自动查询 Pkqa 后尚无 3D chunk，进入玩家区后才加载且画布正常。原预览已暂停持续动画；本次优化主要减少首屏脚本加载，不宣称移动设备性能基准。
4. **版本接口异常可能暴露英文错误。** 非预期 JSON / 网络异常统一显示中文提示，重试恢复；保留明确的已知中文错误。增加 6 项回归，失败时按钮恢复可用。

探针只执行 `-version`，使用 32 / 64 MiB 堆，不执行 MC 或插件。高 CPU 数探针保留真实数值并限定 GC 工作者，避免将参数认可测试变成宿主资源压力测试。JDK 官方包取得后核验 SHA-256，解压在 `coverage/`，没有更改系统 Java。

六种运行时合计 **533 次真实参数探针**。共享判定器每次运行有 34 个独立控制，含实际异常终止与 JVM 参数名含 `OutOfMemoryError` 的合法输出：明确区分参数拒绝、正常认可、已忽略选项、资源不足及崩溃。不能仅凭非零退出码宣布负控通过。

额外修复测试基础设施：相对 `--java` / `--java-home` 路径在切换隔离目录前解析，并用真实参数 / 三版引擎重跑；支持主版本裸输出及补丁版本；下载和解析进程设明确超时；ESLint 忽略下载的 JDK 示例目录。保留失败退出和强校验，不将权限 / 运行时错误当成功。下载挂起分支仅代码核对，未模拟断网。

两份 GitHub 工作流新增 Java 8 / 11 / 16 / 17 / 21 实际参数门槛，随后切换 Java 25 执行三个官方引擎和开服脚本门槛；Linux 的实际结果以发布工作流为准。Java 16 使用官方归档完成兼容复核，不推荐把停止维护的 Java 当作新服通用选择；第三方核心仍应遵循发行版说明。
