# MC 工具工坊第七轮检测

日期：2026-10-02。基于已发布的 `639a127c282e9284cf6636e562e0438d7f6e9bf6`。

## 发现与修复

| 范围 | 问题及修复 |
| --- | --- |
| 物品 / 数据包 | 数量、附魔等级、产物数量、战利品数字不能正常清空重填；现在保留未完成输入，暂停输出及复制，恢复有效整数后继续生成。 |
| 标题 | 播放时间清空被改为 0，越界被静默截断；现在显示具体范围并暂停相关标题。操作栏可独立生成；1.12.2 恢复操作栏配置。 |
| 目标选择器 | 支持空格、引号、嵌套 NBT、scores、advancements、跨环转角及合法重复反选。拦截重复正选、非法选项和类型、@s 的 limit/sort，以及玩家专用指令直接 UUID。允许明确筛选玩家的 @e。 |
| NBT 版本语法 | 核对旧版与 1.21.5+ 的数字、精确 long 范围、浮点溢出、typed 数组、异类列表、bool()/uuid() 和字符转义。Java 与 JavaScript 对空白的判断不同，现对齐 Java 规则；引号内 Unicode 空白保留。 |
| 属性导入 | 完整读取带空格的目标；不再误接受缺少分隔空格的命令。组件空白、尾逗号正常导入。非法未引用文本及数字不能再被转换成合法字符串。清除导入同时清除错误提示。 |
| 描述行数 | 1.20.5+ 最多 256 行描述，Give、导入与数据包共同校验，避免生成官方 codec 拒绝的内容。 |
| ZIP | 拦截超过格式上限的 UTF-8 文件名、重复或非法路径、超量条目及超过 ZIP32 的总尺寸。配方及战利品文件名限制为 1–128 个允许字符。 |
| 实体目录 | 排除不能召唤的 player / fishing_bobber；补回现代目录漏掉的生物、船、矿车、投射物与展示实体。掉落物默认带有效的石头物品数据，避免刚召唤就被游戏删除。 |
| 玩家 / 披风 | 修复披风 A 失败 → B 成功 → A 成功后画布仍隐藏；释放过时预览资源。头像、皮肤及披风图片失败显示占位。接口异常显示中文错误；无效缓存时间不显示 Invalid Date。 |
| 服务器 / 版本 | 主接口故障、备用接口离线时不再称两家均确认离线。版本列表按有效发布时间排序后截取。静态目录拒绝空列表、重复 ID 与非法数值，并提供重试。 |
| 长指令 | 物品、颜色、标题、药水与旗帜对较长输出提示使用命令方块或适用版本的 .mcfunction。 |

## 真实页面检查

- 九个版本都加载成功；1.12.2 操作栏可用，1.8.9 的操作栏和实体召唤隐藏。
- 物品数量、附魔等级、标题时间空输入暂停复制，重填恢复。
- 合法嵌套 NBT / 玩家 @e 选择器可复制；不合法 Unicode 空白与现代玩家专用 UUID 被拦截；引号内空白保留。

- 展开物品目录、6 种药水效果、16 层旗帜，在深浅主题及 320 / 360 / 390 / 768 / 900 / 901 / 1024 / 1440 像素宽度下无整页横向溢出或控件越界。新开页面成功读取版本数据，未记录控制台错误。
- 数据包下载按钮触发后页面无错误；内置浏览器没有回传 download 事件，未据此声称已确认磁盘保存。生成 ZIP 的内容和下载成功/失败清理路径通过独立文件及组件检查。

## 发布门槛及边界

第七轮与独立 ZIP 检查已加入 Pages、PR 工作流，失败停止发布。

官方引擎检查现覆盖 26.1、1.20.4 和 1.16.5 的离线解析 / 部分属性语义；后两项新增证据见 `mc-eighth-qa-2026-10-03.md`。未在全部九个版本的真实世界逐条执行，插件权限、附着实体的支撑条件及第三方 API 缓存仍需按实际环境判断。

本站明确暂不支持 SNBT 的 `\N{字符名称}` 转义，可直接输入字符或使用 `\u` / `\U` 数字转义。部分高级表达式不能用于本站属性导入器，会给出具体提示；其在游戏中的有效性与本站支持范围分别判断。
