## 本轮的独立验证

依据：[Mojang 26.1 发布说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1)（26.1 不再混淆并要求 Java 25）；下载由 [官方版本目录](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json) 定位。

**另对照官方 JAR 内的真实配方资源**：1,684 条网站工作台配方变体全部匹配，覆盖全部 887 种官方有序/无序合成产物；421 条进阶配方的材料、产物、数量、加工时间和经验全部一致。材料标签按官方 item tags 展开；允许镜像、只裁切外围空格，保留中间空行/空列。加入去掉架子配方中间空行的负对照。

这部分合计 10,690 项解析和配方数据检查，并不能等同于游戏内执行 10,690 次。

## 发现并修复

1. **方块坐标超出游戏整数范围**：旧页面可生成 `/setblock 2147483648 64 0 minecraft:stone`，游戏实际解析报 Invalid integer。限制 32 位整数及 X/Z 世界水平边界，显示明确范围；起点错误同时停止 setblock/fill，终点错误只停止 fill。
2. **召唤位置及传送门换算落点越界**：例如下界 X=3,750,000 换算为主世界 X=30,000,000，官方范围检查拒绝。召唤输入校验范围；坐标工具仍展示计算结果和距离，停止生成/复制越界的传送指令。恢复有效输入后按钮正常恢复。
3. **旧版本超过固定填充上限仍可复制**：1.16.5/1.17 等固定上限版本超过 32,768 格时停止生成 fill，setblock 保留；较新版本允许管理员调整规则，仍生成并说明默认上限和规则名。

方块建造高度、区块是否已加载、传送所在维度和实际世界规则依赖游戏环境；界面明确说明，没有把统一的 Y 高度硬套到自定义维度。
